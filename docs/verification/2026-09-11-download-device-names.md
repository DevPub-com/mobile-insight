# 다운로드 기종명 및 데이터 갱신

- Google 공개 기기 목록(`https://storage.googleapis.com/play_public/supported_devices.csv`)의 Device → Marketing Name을 2026-09-11에 반영했다. 36,258개 코드 중 하나의 제품명만 연결된 코드는 제품명과 원래 코드를 표시하고, 여러 제품이 공유하는 코드는 추정하지 않는다. 리뷰에서 우연히 발견한 제품명을 코드 전체에 적용하지 않는다.
- 기기 목록 갱신: 공식 CSV를 내려받은 후 `node --import tsx scripts/update-google-device-catalog.ts <CSV 경로>` 실행.
- 설치 순위는 양수만 포함한다. 상세 표에서는 다운로드·설치 모두 양수가 없는 기종을 제외하고, 남은 행의 0값은 대시로 표시한다. 일별 전체 다운로드의 실제 0값은 보존한다.
- 일별 전체 설치 및 기종별 일반 동기화는 최신 두 월간 보고서를 다시 읽는다. 월 경계 이후 이전 달에 반영되는 지연 데이터를 재수집하기 위한 변경이며, 장기 미수집의 실제 원인이 확인된 것은 아니다.
- 일별 상세 제목 아래 플랫폼별 마지막 실제 다운로드 데이터 날짜를 표시한다. 평점 등 다른 지표의 최신 날짜를 다운로드 기준일로 사용하지 않는다.
- 관련 테스트 21개와 TypeScript 검사 통과.
- 현재 작업 환경에서 `.env.local`을 포함한 환경 로딩 후 DATABASE_URL, GOOGLE_KIS_SERVICE_ACCOUNT_JSON, GOOGLE_KIS_BUCKET_NAME이 모두 미설정임을 확인했다. 운영 보고서 확인·재수집 및 배포는 수행하지 못했다. 실제 최신 일별 데이터 적재는 연결된 환경에서 동기화를 실행한 뒤 검증해야 한다.
