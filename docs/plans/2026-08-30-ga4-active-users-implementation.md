# GA4 활성 사용자 구현 계획

1. GA4 응답 파서와 조회 범위 테스트를 먼저 작성한다.
2. `DailyMetric`과 Drizzle 스키마에 활성 지표 컬럼을 추가하고 마이그레이션을 생성한다.
3. 앱별 GA4 설정과 REST 기반 GA4 수집기를 구현한다.
4. 일반 동기화와 백필 흐름에 GA4 수집을 독립적으로 연결한다.
5. 저장소 매핑과 upsert에 새 필드를 반영한다.
6. 대시보드 overview와 활성 사용자 추이 빌더를 테스트 우선으로 추가한다.
7. 활성 사용자 KPI와 차트를 UI에 추가한다.
8. 전체 테스트, 타입 검사, 린트, 프로덕션 빌드를 실행한다.
